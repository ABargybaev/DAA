1. In this task we need to merge two sorted linked lists into one sorted linked list
2. First we create a dummy node to make building the new list easier and a variable called current to keep track of the last node. Then we compare the first available nodes of both lists. If the value from list1 is smaller or equal we connect that node to our merged list and move list1 to its next node. If it's not we do the same with list2. After each comparison we move current forward. We repeat this until one of the lists becomes empty. Then we just connect the remaining nodes from the other list because they're already sorted. Then we return dummy.next which is the actual head of our merged list
3. The time complexity here is O(n+m), n and m - numbers of nodes in the two linked lists. Because we need to go through both lists
4. The space complexity here is O(1) because we don't create any additional arrays or lists. We only create one dummy node and use a few variables to connect the existing nodes 
5. I think my solution is pretty simple and efficient. Since both lists are already sorted we don't need to sort them again. We just compare their values and connect the nodes in the correct order
