1) So the point of this problem is that we need to find the targetted number in the array and return its' positiion in the array. But there is a possibility that the number isn't even in the array so we need to return -1 in this case
2) My solution works really simple, we just check every element in the array and compare it to the targetted number. If it's the same, it returns 1. If it's not the same, we continue the comparing. If the target isn't in the array we return -1
3) Here time complexity is O(n) because my solution in the worst case will check every element in the array which means the complexity is O(n)
4) Space complexity is O(1) because my solution is really simple, we just check every element without creating any extra elements or array and stuff like that
5) I think my solution is the most basic and the most effiecient one, it just checks every element one by one, it even works in an unsorted array. So yeah, it's the best solution in my opinion
