1. In this task we need to find all the paths from the root of a binary tree to its leaf nodes
2. First we create an arraylist to store the paths. Then we use a separate method called findPaths. If the current node is null we just return. If it's not we add its value to our path string. Then we check if the node is a leaf. If it is we add the completed path to our list. If it's not a leaf we check the left and right children and continue building the paths
3. The time complexity here is O(nh), n - number of nodes, h - height of the tree. We visit every node once but we also create new strings when building the paths which takes extra time. In the worst case, if the tree is completely skewed the complexity can be O(n²)
4. The space complexity here is O(n²) in the worst case because we create new strings for the paths. In a completely skewed tree the recursive calls can keep strings of increasing lengths in memory. We also use an arraylist to store the final paths
5. I think my solution is pretty simple and easy to understand. We just go through the tree and build strings until we reach a leaf node. I like that we don't need any complicated algorithms or additional data structures except an arraylist. But I would like to see other more effecient sollutions in terms of memory usage
